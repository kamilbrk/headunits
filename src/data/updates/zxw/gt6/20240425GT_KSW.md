#### Summary
- New theme ID `KSW_AUDI_PORSCHE`: `<Item id="43" ui="KSW_AUDI_PORSCHE" />` (only the ID is added; no screens use it yet)
- UI license activation checks through a file (or online service as a fallback) for the Sailor T002/T003 and Knight T001 UIs
- MCU upgrade files are now verified for corruption before installation

#### Changes
- Added UI activation verification with a license file under `/mnt/privdata1/activation/LicenseData_{BrandUiName}.lic` or through a fallback online service on ZXW servers under POST `https://devices.cosciv.com/ksw/machineRecord/activate`. The check only runs for UIs above ID `100`. If verification fails and the user presses "Reboot" on the activation window, UI ID `100` (`KSW_SAILOR_T001`) will be set.
- Bluetooth app added "BT Upgrade" functionality; added buttons to manage Bluetooth volume (on `KSW_BMW_ID8_COPILOT` and Land Rover themes)
- New factory config option "LCD CLK Polarity" (`lcdClkPolarity` in XML)
- New factory config option `replaceVersionWith8953` in XML, whereby firmware will swap the `GT6` (or `GT7`) part of version text to show `8953` instead, and also rewrite the `EAU`/`NA` part and the Bluetooth module version
- Music player has a new file list screen for BMW ID6 theme
- MCU upgrade files are now verified and users will see `MCU upgrade file is damaged!` message if the sum of the file's bytes (excluding the last 24 bytes) does not match the value stored in bytes `len-14` to `len-11` of the file
